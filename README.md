# GrooveJolt

GrooveJolt enables auto-scaled, multi-threaded workflows with low-latency execution for real-time data processing and job management.

GrooveJolt is built to be simple and practical, focusing on doing one thing well.

**Why GrooveJolt?**

- GrooveJolt enables auto-scaled, multi-threaded workflows
- with low-latency execution for real-time
- data processing and job management

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/GrooveJolt.git`
2. `cd GrooveJolt`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
